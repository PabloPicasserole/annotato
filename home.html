Mark up a design with pins, boxes, arrows, drawings and sticky notes, then export everything for Claude in one go. Feedback is saved in the project you review, never here.

A mock or page on disk

Any HTML file or folder of pages, like the prototypes Claude builds. Shortcut: drag it onto Review a mock.cmd, or right-click it and choose Send to › Review a mock.

A running app

An app on a dev server, like a React or Vite app at localhost:5173. Start it first (usually npm run dev, or ask Claude to).
